# scoop-apps — Apps de Javiera Navarrete para Windows / Windows apps (Scoop bucket)

**Español.** Bucket de [Scoop](https://scoop.sh) con las apps de escritorio para Windows (versiones portables; requieren Microsoft Edge WebView2, incluido en Windows 11). Los ejecutables no están firmados con certificado de código.

```
scoop bucket add apps https://github.com/navarretenoir/scoop-apps
scoop install apps/clima          # Clima — aplicación del clima de Chile
scoop install apps/metro-chile    # Metro Chile — estado en vivo del Metro de Santiago (no oficial)
scoop install apps/escala-notas   # Escala de Notas — notas escolares chilenas, 1,0 a 7,0
scoop install apps/tumundopet     # Tu Mundo Pet — tienda de acuarismo y mascotas
```

**English.** [Scoop](https://scoop.sh) bucket with the Windows desktop apps (portable builds; they need Microsoft Edge WebView2, included in Windows 11). The executables are not code-signed.

Metro Chile is an **unofficial** app, not affiliated with Metro S.A. / App no oficial, no afiliada a Metro S.A.
